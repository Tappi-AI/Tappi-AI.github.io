# Tappi

<p class="lede">One flexible primitive — tables with rows, columns, and multiple views —
that you shape into whatever workflow you need. Add AI where it helps, keep
full control everywhere else.</p>

<a class="cta" href="{{ '/esg-demo/' | relative_url }}">See the ESG demo →</a>

## Built on one primitive

<ul class="features">
  <li><strong>Tables that adapt</strong> Rows and columns with the field types you need — text, docs, tags, dates, checkboxes.</li>
  <li><strong>Views, not just rows</strong> Table, kanban, and timeline views over the same data — pick the lens that fits the moment.</li>
  <li><strong>A doc per row</strong> Every row can carry its own rich document, so context lives next to the data.</li>
  <li><strong>AI-assisted, not AI-locked</strong> Bring AI in for drafting and summarizing where it helps — the table stays the source of truth.</li>
</ul>

## Featured demo: ESG traceability

Supply chains generate a lot of scattered paperwork — certifications, origin
records, carbon numbers. Tappi turns that into one table: a row per product,
a document per certification, a view per audience.
