Tappi · Structured work, one primitive

Tables that carry their own evidence

Rows, columns, documents, and multiple views over the same data — shaped into whatever workflow you need. Add AI where it helps, keep full control everywhere else.

See the ESG demo What Tappi is

Built on one primitive

  • Tables that adaptRows and columns with the field types you actually need — text, docs, tags, dates, checkboxes.
  • Views, not just rowsTable, kanban, and timeline views over the same records — pick the lens that fits the moment.
  • A document per rowEvery row carries its own rich document, so evidence and context live next to the data.
  • AI-assisted, not AI-lockedBring AI in for drafting and summarizing; the table stays the source of truth.

Supply chains scatter evidence across certifications, origin records and carbon numbers. Tappi keeps it as one table — a row per product, a document per certification — and publishes any row as a shareable product passport.
